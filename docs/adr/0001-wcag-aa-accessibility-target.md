# Adopt WCAG 2.2 AA as the site's accessibility conformance target

During the first dedicated accessibility pass on the site (August 2026), several issues surfaced (non-keyboard-operable theme toggle, sub-AA link contrast, language mismatches, motion not respecting `prefers-reduced-motion`). Rather than fixing them ad hoc with no stated bar, we're adopting WCAG 2.2 level AA as the site's declared conformance target going forward. Future changes — new components, color tokens, interactive elements — are expected to meet AA; AAA is not a goal.
